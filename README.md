# KiCad DRL → CNC3018 (GRBL TAP)

Конвертер файлов сверловки **KiCad / Excellon (`.drl`)** в G-code **GRBL (`.tap`)** для станков класса **CNC 3018**. Python 3, **без сторонних библиотек**. Проверен программно на четырёх реальных DRL-файлах, экспортированных из **KiCad 10.0.1**. **На физическом станке обновлённая версия не проверялась.**

> ⚠️ Программа генерирует управляющие команды для реального оборудования. Перед запуском обязательно проверьте размеры, ноль Z, ориентацию платы, рабочую область станка, программу в визуализаторе Candle/UGS и выполните сухой прогон над платой. Вы несёте ответственность за параметры сверления и безопасность станка.

## Что умеет

- Читает метрические DRL KiCad с форматом `FORMAT={3:3/...}` и **keep zeros**.
- Учитывает выбранные инструменты (`T1`, `T2`, …), а не только их объявления в заголовке.
- **Создаёт отдельный `.tap` на каждый диаметр сверла**: на обычном 3018 инструмент меняется вручную. Одинаковые диаметры объединяются.
- Сохраняет координаты KiCad, в том числе отрицательные Y, сортирует сверления по X и Y.
- Позволяет задать безопасную Z, высоту подхода, глубину, подачу, команду `S` и задержку раскрутки шпинделя.
- Выявляет **фрезеруемые пазы/слоты**: по умолчанию останавливает преобразование, поскольку **сверло нельзя безопасно использовать для бокового фрезерования**. Допускает `--skip-slots`, если пазы будут обрабатываться отдельно.

## Установка и запуск (Windows 10/11)

1. На странице репозитория нажмите **Code → Download ZIP**, распакуйте архив.
2. Один раз запустите **`install.bat`**. Если Python не найден, скрипт предложит установку Python 3.13 через `winget`. После установки откройте новый терминал. Интернет требуется только для установки Python.
3. Перетащите `.drl` на **`start.bat`** либо дважды щёлкните `start.bat` и введите полный путь к DRL.
4. `.tap` появятся **рядом с исходным `.drl`**, по одному на диаметр: например `board_0p800mm.tap`, `board_1p000mm.tap`.
5. Откройте полученные траектории в **Candle**, **UGS** или аналогичном GRBL-контроллере и проверьте их перед выполнением.

Внимание: если Python уже установлен, `install.bat` ничего скачивать не должен. Модули через `pip` не требуются.

## Экспорт сверловки из KiCad

В **PCB Editor → File → Fabrication Outputs → Drill Files** экспортируйте файл Excellon в **миллиметрах**, абсолютные координаты, **keep zeros**. Для обычной сверловки используйте `.drl` с круглыми отверстиями. Пазы могут присутствовать в таком же файле и требуют отдельной обработки.

Координаты **не перемещаются в начало платы** автоматически. В ряде экспортов KiCad Y отрицательный — это нормально для исходных данных, но перед запуском станка необходимо выставить правильный **рабочий ноль X/Y**. Z=0 в типовом сценарии — верх поверхности платы.

## Командная строка

```powershell
python drl_to_tap.py "C:\Projects\board.drl"

# Отдельный каталог; пропустить продолговатые пазы (их придётся обработать отдельно)
python drl_to_tap.py "C:\Projects\board.drl" --output-dir "C:\Projects\cnc" --skip-slots

# Глубина, безопасная высота и подача
python drl_to_tap.py board.drl --z-safe 5 --z-approach 0.5 --z-drill -1.8 --feed 40 --spindle 1000 --dwell 3
```

| Аргумент | По умолчанию | Значение |
| --- | ---: | --- |
| `--z-safe` | `5` | Безопасная высота над Z=0, мм |
| `--z-approach` | `0.5` | Быстрое опускание до высоты подхода, мм |
| `--z-drill` | `-2.4` | Рабочая глубина, мм |
| `--feed` | `50` | Подача Z в мм/мин |
| `--spindle` | `10000` | **Значение GRBL S**, не гарантированные об/мин |
| `--dwell` | `2` | Пауза раскрутки шпинделя, секунды |
| `--output-dir` | рядом с DRL | Папка с выходными файлами |
| `--skip-slots` | выключено | Пропускать фрезеруемые пазы с предупреждением |

**Важно про шпиндель:** в GRBL значение `S` зависит от настройки контроллера **`$30`** (например, `$30=1000` либо `$30=10000`). Убедитесь, что используете корректную шкалу; `S10000` в программе не означает автоматически 10 000 физических об/мин.

## Какой получается G-code

```gcode
G21
G90
G94
G0 Z5.000
M3 S10000
G4 P2.00
G0 X5.000 Y-5.000
G0 Z0.500
G1 Z-2.400 F50
G0 Z5.000
M5
M2
```

Это сокращённый пример, а не готовая полная программа. На каждый диаметр выпускается отдельный файл, без автоматической смены инструмента.

## Ограничения

- Только **метрические** DRL с явно указанным форматом координат или десятичными координатами; поддержка Excellon zero-suppression (`LZ`/`TZ`) пока не реализована.
- Пазы и контурная фрезеровка **не генерируются**: по умолчанию ошибка; `--skip-slots` пропускает их явно.
- Не поддерживается автоматическая пробивка нескольких глубин (peck drilling), компенсация люфта, автоуровень, корректировка толщины заготовки и проверка пределов перемещения станка.
- Программа не управляет самой CNC3018 и не гарантирует совместимость с любой прошивкой: выход предназначен для **GRBL**.
- При повторном запуске соответствующие TAP-файлы перезаписываются.

## Проверки

```powershell
python -m unittest discover -s tests -v
python drl_to_tap.py examples/sample_board.drl --output-dir output
```

На предоставленных четырёх DRL из KiCad 10 проверена читаемость файлов и корректное разделение круглых отверстий по диаметрам. В двух исходниках дополнительно найдены продолговатые пазы: по умолчанию они корректно блокируются, при `--skip-slots` круглые отверстия генерируются без пазов. Исходные PCB-проекты в репозиторий не включены.
